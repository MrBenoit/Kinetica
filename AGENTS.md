# Kinetica

Personal Obsidian plugin. Use English in source, comments and repository docs.
Localize visible UI strings in src/i18n.ts. Keep English and Russian in sync.
No services, telemetry or network access at runtime. Never evaluate JavaScript from a note.
Documents use a versioned JSON format inside motion fenced blocks. Preserve surrounding Markdown and detect concurrent edits before saving.
Keep rendering and document validation independent of the Obsidian adapter.
Run npm run check before delivering a build. Validate the build in Obsidian too.
Do not publish, commit or modify unrelated vault content without a user request.
