# Kinetica 0.2.1 beta

Use Obsidian's API version check before refreshing declarative settings. Older hosts keep the legacy settings interface. The minimum supported Obsidian version stays at 1.8.7.

Includes the HTML viewer from 0.2.0, with English and Russian controls, translated validation errors and a bilingual example page. Download kinetica.js and kinetica-example.html into the same folder to try it.

Obsidian installs main.js, manifest.json and styles.css. The two browser files are separate downloads. All five files have GitHub artifact attestations.
