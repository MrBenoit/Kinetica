# Kinetica HTML viewer

Download both files into the same folder and open kinetica-example.html in a browser. The full Plotly runtime and styles are included locally.

These files are for HTML pages. Install the Obsidian plugin from the matching numbered release. The HTML release is marked as a prerelease so it does not replace the plugin as the latest release.

You can also export a visualization as one HTML file from the plugin.
