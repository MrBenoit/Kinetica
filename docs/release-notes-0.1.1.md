# Kinetica 0.1.1 beta

Language settings now appear in Obsidian settings search on version 1.13 and later. Older supported versions keep the existing settings screen.

The formula function table uses explicit types. Document replacement no longer uses an unnecessary type assertion. The document format and the standalone renderer are unchanged.

Release files are built, tested and attested in GitHub Actions. The release contains only `main.js`, `manifest.json` and `styles.css`.

The plugin remains an early beta. Desktop use is tested on macOS. Mobile devices and other desktop operating systems still need testing.
