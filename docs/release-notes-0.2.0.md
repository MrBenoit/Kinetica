# Kinetica 0.2.0 beta

Embed scenes and interactive graphs in ordinary HTML pages with `<kinetica-player>`.

Download `kinetica.js` and `kinetica-example.html` into one folder. Open the HTML file to try two players, then copy a JSON document from an Obsidian motion block into your page. No Obsidian installation, framework or server is needed for viewing.

The web viewer includes dark, light and system themes, English and Russian controls, isolated styles and cleanup when removed from a page. The document format is unchanged.

For Obsidian, install only `main.js`, `manifest.json` and `styles.css`. The two web files are separate downloads and are ignored by the Obsidian installer. All five release files are built and attested in GitHub Actions.

This is still an early beta. Mobile devices and other desktop operating systems need testing.
