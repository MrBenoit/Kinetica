# Kinetica 0.3.0

- Highlight active code lines and show variable values per scene step
- Add prediction questions with answer explanations and playback gates
- Explore queues, buffers and worker pools with linked diagrams, metrics and charts
- Compare worker counts or synchronize two scenes
- Import Python Plotly figure JSON with the full local Plotly runtime
- Export a visualization as one standalone HTML file from the player or editor
- Keep English and Russian controls, dark and light themes, and version 1 documents

Plotly runs in an isolated frame with network access blocked. Geographic maps and remote resources are not supported. Python scripts are not executed. The full runtime increases the viewer to about 5 MB and the plugin to about 10 MB.
